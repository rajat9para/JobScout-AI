STEP 6: DEPLOY ON RENDER
================================================================================

[ ] 6.1 Create Blueprint Instance
      → In Render Dashboard, click "Blueprints"
      → Click "New Blueprint Instance"
      → Connect your GitHub account
      → Select the "jobscout-v2" repository
      → Render will detect render.yaml automatically

[ ] 6.2 Add Environment Variables
      → Render will show 3 services:
        • jobscout-v2-web (Web Service)
        • jobscout-v2-scraper (Cron Job - hourly)
        • jobscout-v2-reminders (Cron Job - daily 8 AM)

      → FOR EACH SERVICE, click into it:
        • Go to "Environment" tab
        • Click "Add Environment Variable"
        • Add ALL variables from your .env file ONE BY ONE
        • For sync: false vars, manually enter the value

      → Variables to add for ALL 3 services:
        SUPABASE_URL, SUPABASE_KEY, SUPABASE_SERVICE_KEY,
        TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN,
        TWILIO_WHATSAPP_NUMBER, USER_WHATSAPP_NUMBER,

        APP_ENV, LOG_LEVEL, SCRAPE_INTERVAL_MINUTES

[ ] 6.3 Deploy

      → Render builds all 3 services (takes 3-5 minutes)
      → Wait for all to show "Live" status

        https://jobscout-v2-web-xxxx.onrender.com

STEP 8: SETUP UPTIMEROBOT (CRITICAL — DO NOT SKIP)
================================================================================

[ ] 8.1 Create Monitor
      → In UptimeRobot Dashboard, click "Add New Monitor"
      • Monitor Type: HTTP(s)
      • Friendly Name: JobScout Keep Alive
      • URL: https://jobscout-v2-web-xxxx.onrender.com/health
      • Monitoring Interval: Every 5 minutes (300 seconds)
      • Click "Create Monitor"

[ ] 8.2 Why This Matters
      → Render free web services SPIN DOWN after 15 min idle
      → Without UptimeRobot, Twilio webhooks will FAIL
      → UptimeRobot pings /health every 5 min keeping it alive
      → This is the ONLY way to make free tier reliable

================================================================================
TROUBLESHOOTING QUICK FIXES
================================================================================

Problem: "Webhook not responding"
Fix: Check UptimeRobot monitor is green. Check Render service is "Live".

Problem: "No job alerts after hours"
Fix: Check cron job logs. Check profile status = active. Check interests match.

Problem: "Twilio says 'not a valid WhatsApp number'"
Fix: Ensure USER_WHATSAPP_NUMBER has +91 country code. No spaces.

Problem: "Database connection error"
Fix: Check SUPABASE_SERVICE_KEY (not anon key). Re-run schema.sql.

Problem: "Gemini rate limit exceeded"
Fix: Wait 1 minute. Reduce scrape frequency to 2 hours in render.yaml.

Problem: "Resume upload failed"
Fix: Check "resumes" bucket exists in Supabase Storage. Check permissions.
